Playlist Exporter

A local macOS app for getting Music.app playlists onto a memory card in the right order, plus a searchable offline index of a much larger NAS archive independent of Music.app. No Apple Developer account, no cloud service — everything runs on your own Mac against your own files.

This site documents what's built and how it behaves, including known limitations — not just the happy path. If a feature has a caveat, it's called out on that feature's page, not buried in a changelog.

Features

Playlists → Memory Card
Export Music.app playlists to a plain folder structure, numbered for car head units. Skips DRM and missing tracks with a visible reason.
Restore Missing Tracks
Matches a playlist's missing tracks against your NAS index and re-attaches them automatically — with a known ordering limitation.
Search / Library Index
Full-text search across a raw filesystem scan of your NAS archive, independent of Music.app.
Metadata Enrichment
Background lookups against Apple's iTunes Search API fill in missing tags and write them back into the actual files — permanently.
Duplicates
Byte-identical and same-title duplicate detection across your archive, with safe, rule-based cleanup.
Native macOS App
A real Dock-icon app (Swift + WKWebView) around the same local server — self-contained, relocatable, with a proper menu bar.

How it's built

A local Node.js/Express server (server.js) plus a plain browser UI — no framework, no build step. Two independent data sources feed it:

  • Music.app itself, via AppleScript (osascript) — the Playlists tab.
  • A raw filesystem crawl of a NAS archive, stored in a local SQLite index — the Search, Library Index, Queue, Not Found, and Duplicates tabs.

See Development & CI for how it's tested, versioned, and built.
