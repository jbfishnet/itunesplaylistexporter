Duplicates

Built on the same index as Search — two sections, two different safety rules.

Exact Duplicates

Files that are byte-identical (same content hash). Always safe to delete: one copy per group is kept (whichever was indexed first), and the rest can be deleted individually or all at once.

Similar Titles

Files that share a title but differ in some other way (artist, album, format, size, …) — not confirmed identical, so this could be a real duplicate or a genuinely different recording (a live version, a cover, a remix).

Deletion here follows one hard rule: a copy under the canonical NAS archive path is never deleted — it's always the one kept. If a group has no copy under that path, the oldest-indexed copy is kept instead. The server re-derives and enforces this on every delete request regardless of what the client sends, so a stale or racing UI state can never delete the protected copy.

Deletes in this section fire immediately (no confirmation dialog), per-file, per-group ("Delete other copies"), or for every group at once ("Delete All Non-Canonical Copies").

Both sections delete the file from disk permanently (not to the Trash) and remove it from the index — this can't be undone.
